### 🧬 Bienvenido al Laboratorio

**SENKU-BOT** es una herramienta desarrollada para WhatsApp basada en la lógica y el pensamiento científico de *Senku Ishigami*. Automatiza procesos, gestiona grupos y facilita la vida en tu aldea digital.

--- 

### 🧪 Funciones Principales

• **Sistema Modular:** Comandos organizados mediante plugins.
• **Multimedia:** Descarga de audio/video (TikTok, IG, FB).
• **Gestión:** Herramientas completas para moderar grupos.
• **Rendimiento:** Optimizado para operar 24/7 sin colapsar.

--- 

### ⚙️ Instalación Rápida

```bash
git clone https://github.com/Andresv27728/SENKU-BOT
cd SENKU-BOT
npm install
npm start
```

--- 

### 📂 Arquitectura del Sistema

*   `index.js`: El reactor principal, inicializa el servidor.
*   `handler.js`: El cerebro, procesa los mensajes y eventos.
*   `lib/`: Bibliotecas de funciones esenciales.
*   `plugins/`: Aquí reside la lógica aplicada de cada comando.
